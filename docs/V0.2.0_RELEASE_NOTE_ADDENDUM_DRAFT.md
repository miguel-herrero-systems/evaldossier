# Draft addendum for the v0.2.0 GitHub release

> Publish this note only after v0.2.1 exists, then replace the link below with the confirmed release URL.

## Superseded standalone plugin payload

The v0.2.0 standalone Codex plugin ZIP included three deterministic Ed25519 private JWK fixtures used only by its fixed synthetic conformance workflow. Those keys were deliberately public, compromised test material committed in the repository; they were never production credentials and established no external identity or trust.

Even so, distributing private JWK components was unnecessary and created avoidable review ambiguity. EvalDossier v0.2.1 replaces them with fresh in-memory test keys, adds a CI gate that rejects private key material from agent-plugin payloads, and documents that live conformance dossiers are semantically stable rather than byte-reproducible.

The v0.2.0 release remains available as a transparent historical artifact. Use [v0.2.1](https://github.com/miguel-herrero-systems/evaldossier/releases/tag/v0.2.1) for installation or marketplace review.
